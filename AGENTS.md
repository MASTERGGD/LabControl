# Continuidad de SIGA

Antes de modificar este repositorio, leer `docs/CONTINUIDAD_SIGA.md` y las entradas recientes de `CHANGELOG.md`.

Al terminar un cambio funcional, registrar en `CHANGELOG.md` su fecha, problema, comportamiento resultante, validación y pendientes. Distinguir cambios preparados de cambios publicados; no afirmar un despliegue sin verificarlo. El hash del commit se puede consultar con Git para evitar autorreferencias al escribir la entrada.

Conservar los cambios ajenos que ya existan en el árbol de trabajo. No incluir credenciales, información personal, respaldos ni archivos temporales en commits o documentación de continuidad.
